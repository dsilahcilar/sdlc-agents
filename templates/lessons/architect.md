# Architect lessons

Decisions made in this repository and the reason for each, in short. The architect reads this file before every review.

- One entry is one or two lines: the date, where the decision was made, the decision and its reason.
- At most 40 lines of entries. To add one when the file is full, take one out.
- An entry leaves when a check in code enforces it, or after 90 days in which no review used it.
- Entries arrive in their own pull request, never inside a change they would judge.
